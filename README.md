A responsive personal website built with HTML, CSS, and vanilla JavaScript. It runs locally without a backend or build step.

## Open the site

Open `index.html` in a browser. For automatic refresh while editing in VS Code, you can use the Live Server extension; it is optional.

## Customize the site

- **Name and story:** Edit the Home and My Story text in `index.html`.
- **Portrait:** Replace `assets/images/ariane-profile.jpg` with your photo, keeping the same filename.
- **About video:** The About section plays `assets/images/about-me.mp4`. Replace that file to change the clip; use the browser controls for playback, seeking, volume, and fullscreen; the three-dot menu changes playback speed.
- **Hobbies:** Edit the Creative Design and Reading Book sections in `index.html`. Their photos are `assets/images/creative-ideas.jpg`, `creative-design.jpg`, and `reading-book.jpg`.
- **Social icons:** Replace the Facebook, Instagram, and TikTok images in `assets/images/`. Add your profile URLs to the social items in `index.html` if you want them to link to your accounts.
- **Colors and spacing:** Change the CSS variables at the top of `style.css`.

The contact form validates the entries and displays a confirmation in the browser. It does not send or store messages until connected to a submission service.
